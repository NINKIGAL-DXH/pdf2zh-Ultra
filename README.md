# PDF2ZH Ultra

**PDF2ZH Ultra** 是一款基于顶尖开源项目全新开发的高保真双语翻译及排版可视化客户端环境。它是从底层构建的一站式双语格式阅读、模型接入及智能转化平台。

## 致谢开源贡献者

该项目深度基于极具开创性的卓越开源项目：**[PDFMathTranslate](https://github.com/PDFMathTranslate/PDFMathTranslate)** 

**特此由衷感谢原开源团队及作者在文档布局识别（Layout-Parser）、PDF 公式清洗引擎、双语融合结构编排上的无私贡献！** PDF2ZH Ultra 将该项目的核心翻译解析能力与高交互性的前端环境完美融合，旨在为用户提供零摩擦的部署与阅读体验。

---

## 核心特性与功能

- 📄 **原生级排版还原:** 利用并优化自 PDFMathTranslate 技术的文档结构保留方案，实现对学术论文、图表、多栏段落的像素级镜像。双重支持并列导出 PDF 与高保真 HTML。
- ⚡ **无阻滞智能工作流:** 完全抛离命令行的沉浸式参数映射控制，全过程可视化，提供全环境自检自愈控制流（智能诊断环境及服务状态）。在应用中直观查看执行进度和耗时。
- 🧠 **自定义服务与提示词系统 (Prompts/Engines):**
  - 支持多路并发及自定义配置接口（Gemini、OpenAI、LM Studio、Ollama、自定义端点支持）。
  - 内置深度的学术、法律、医学提示设定，且允许随需保存个性化的 System Prompts 进行风格干预。
- 📖 **行业与领域专家词汇库 (Glossary):**
  - 免去二次繁琐校队，可加载内置或外部定义的术语库表（CSV/Txt），系统级统一核心概念释义和领域特殊词汇。
- 🖥 **一键生成转化指令 (CLI Quick Generate):** 针对部分需集成至 CI/CD 或终端脚本的极客或专业工作流，可基于当前面板设定光速输出安全的终端执行代码（含全部正则表达式预处理等）。
